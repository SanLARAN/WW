# WorldWide (WW)

Геополитическая стратегия в реальном времени на 3D-глобусе: реальные страны 2020 года, реальные события 2020–2024 и альтернативная история, бесконечная симуляция, мультиплеер до 16 игроков.

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # продакшен-сборка в dist/
npm run typecheck
```

Нужен браузер с WebGL2 (Chrome, Edge, Firefox, Safari 16.4+).

## Что внутри

| Слой | Где | Что делает |
|---|---|---|
| Мир | `src/world/` | Растеризация границ Natural Earth, ~3000 провинций (взвешенный Вороной по ночным огням), рельеф по реальной карте высот и спутниковым снимкам, навигационная сетка и A* |
| Данные | `src/data/` | Страны 2020 (ВВП, армия, ядерка, альянсы, идеология), города, месторождения, техника, ракеты, технологии, фокусы, события |
| Симуляция | `src/game/` | Время, экономика, ресурсы, политика, бой, захват провинций, ПВО, ракеты и ЯО, ИИ, дипломатия, события |
| Графика | `src/render/` | Шейдер глобуса (провинции, оккупация, день/ночь, огни городов), атмосфера, облака, юниты, частицы ракет/взрывов/ядерных ударов, пост-обработка |
| Звук | `src/audio/` | Полностью процедурный звук на Web Audio: генеративная музыка, радиоэфир, пуски, взрывы, сирена |
| Сеть | `src/net/` | Хост-авторитетная модель: WebRTC P2P, сигналинг и резервная ретрансляция через Supabase Realtime |
| UI | `src/ui/` | Preact: меню, выбор страны, лобби, HUD, панели |

## Мультиплеер

- Без Supabase игра работает в **локальном режиме**: комнаты видны между вкладками одного браузера (удобно для тестов).
- С Supabase — онлайн. Нужен только проект Supabase (таблицы не нужны, используется Realtime Broadcast):
  1. Создайте проект на [supabase.com](https://supabase.com).
  2. Settings → API: скопируйте **Project URL** и **anon public key**.
  3. Локально: создайте `.env.local` по образцу `.env.example`.
  4. Для GitHub Pages: Settings → Secrets and variables → Actions → добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
  5. Либо вставьте их прямо в игре: «Настройки → Сеть».

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает и публикует сайт при каждом пуше в `main`.
В репозитории: **Settings → Pages → Source: GitHub Actions**.

## Источники данных

- Границы: Natural Earth через `world-atlas` (public domain).
- Спутниковые снимки, ночные огни, рельеф: NASA Blue Marble / Black Marble (public domain), файлы из `three-globe` (MIT).
