# WorldWide (WW)

Геополитическая стратегия в реальном времени на 3D-глобусе: реальные страны 2020 года, реальные события 2020–2024 и альтернативная история, бесконечная симуляция, мультиплеер до 16 игроков.

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # продакшен-сборка в dist/
npm run typecheck
```

Нужен браузер с WebGL2 (Chrome, Edge, Firefox, Safari 16.4+).

## Что внутри

| Слой | Где | Что делает |
|---|---|---|
| Мир | `src/world/` | Растеризация границ Natural Earth, ~3000 провинций (взвешенный Вороной по ночным огням), рельеф по реальной карте высот и спутниковым снимкам, навигационная сетка и A* |
| Данные | `src/data/` | Страны 2020 (ВВП, армия, ядерка, альянсы, идеология), города, месторождения, техника, ракеты, технологии, фокусы, события |
| Симуляция | `src/game/` | Время, экономика, ресурсы, политика, бой, захват провинций, ПВО, ракеты и ЯО, ИИ, дипломатия, события |
| Графика | `src/render/` | Шейдер глобуса (провинции, оккупация, день/ночь, огни городов), атмосфера, облака, юниты, частицы ракет/взрывов/ядерных ударов, пост-обработка |
| Звук | `src/audio/` | Полностью процедурный звук на Web Audio: генеративная музыка, радиоэфир, пуски, взрывы, сирена |
| Сеть | `src/net/` | Хост-авторитетная модель: WebRTC P2P. Сигналинг — Trystero (~30 публичных nostr-релеев параллельно, без ключей), Supabase Realtime или локальный BroadcastChannel |
| UI | `src/ui/` | Preact: меню, выбор страны, лобби, HUD, панели |

## Мультиплеер

Из коробки работает **онлайн P2P**: хост создаёт комнату и диктует другу код, клиент вводит код — браузеры соединяются напрямую через WebRTC (для знакомства пиров используется Trystero — пакет публичных релеев работает параллельно, достаточно одного живого; игровой трафик идёт P2P). Ничего подключать не нужно.

- Supabase — необязательная альтернатива (свой сигналинг + список открытых комнат):
  1. Создайте проект на [supabase.com](https://supabase.com).
  2. Settings → API: скопируйте **Project URL** и **anon public key**.
  3. Локально: создайте `.env.local` по образцу `.env.example`.
  4. Для GitHub Pages: Settings → Secrets and variables → Actions → добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
  5. Либо вставьте их прямо в игре: «Настройки → Сеть».
- Без интернета релеи недоступны — комнаты работают в **локальном режиме** между вкладками браузера.
- Ограничения: ~5–10% пар с жёсткими NAT могут не соединиться даже через TURN — тогда поможет VPN или другой хост.

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает и публикует сайт при каждом пуше в `main`.
В репозитории: **Settings → Pages → Source: GitHub Actions**.

## Источники данных

- Границы: Natural Earth через `world-atlas` (public domain).
- Спутниковые снимки, ночные огни, рельеф: NASA Blue Marble / Black Marble (public domain), файлы из `three-globe` (MIT).

## Кампания, сохранения и флот

- **Кампания на 10 лет** (`src/game/campaign.ts`): 6–7 целей под масштаб страны, счёт, финальный экран с вердиктом. Прогресс кампании лежит внутри `GameState.campaign`, поэтому сохраняется и переживает сеть.
- **Сохранения** (`src/game/save.ts`): 1 автослот + 3 ручных, gzip+base64 в `localStorage` (~260 КБ на середину партии). «Продолжить» в главном меню; автосейв каждые 45 с и при выходе.
- **Блокада**: вражеский флот у побережья режет торговлю и доход (до −55%), помечает берег красным и пишется в военной полосе. Флот перестал быть декорацией.
- **Стратегический слой** (`src/game/strategy.ts`): доктрины, модернизация, оперативные очки (удары, давление, влияние, диверсии, снабжение). ИИ принимает доктрину и играет по ней.

Горячие клавиши: `O` — командование, `F` — фокусы, `R` — наука, `H` — оборона, `Alt+клик` — удар, двойной клик — приблизить, `Пробел` — пауза, `1–5` — скорость.
