# КОТЁЛ

Тактическое выживание малой группой. Борт сбит над лесополосой: вокруг брошенные
пятиэтажки, окопы, дачи и обломки. Снабжение прилетает редко, враг — постоянно.
Один в поле или до шести своих по прямой P2P-связи.

**Играть:** включите Pages в настройках репозитория (`Settings → Pages → Source: GitHub Actions`),
пуш в `main` соберёт и выложит игру.

## Что внутри

- **Полностью процедурный мир.** Карта 260×260 м строится из зерна: 45 объектов
  (пятиэтажки, сараи, контейнеры, бункер, окопы, бруствер из мешков, разбитая
  техника), 400+ деревьев, воронки, обломки вертолёта. Одно зерно — один и тот же
  мир у всех в отряде.
- **Текстуры и звук без единого файла ассетов.** Albedo, roughness и карты
  нормалей рисуются на canvas при загрузке (процедурный fBm-шум, Sobel для
  нормалей). Каждый выстрел, взрыв, ветер и автоматная очередь синтезируются в
  WebAudio. Поэтому сборка весит меньше мегабайта и грузится с GitHub Pages без
  внешних CDN.
- **Погода и свет.** Тяжёлый низкий облачный фронт как единственный источник
  света, экспоненциальный туман, моросящий дождь, ползущая дымка в лесополосе.
- **Пост-обработка.** SMAA, плёночный грейд с холодными тенями, виньетка,
  зерно, хроматическая аберрация, покраснение по краям от ранений, обесцвечивание
  при подавлении.
- **Реалистичная камера.** Инерция обзора, пружинная высота глаз, шаговое
  покачивание с боковым креном, отдача отдельным пружинным каналом, FOV на бег и
  на прицел, тряска от близких разрывов.
- **Оружие с характером.** АК-74М, Сайга-12, СВД, ПКМ, FPV-дрон. Накопление
  отдачи при длинной очереди, падение урона по дистанции, штраф за бег и
  приседание, разброс от подавления.
- **Волны и ИИ.** Пехота наступает по навигационному полю (BFS-поток на сетке
  2 м), дроны и FPV охотятся персонально, техника приходит каждую четвёртую волну.
  ИИ-бойцы отряда воюют теми же примитивами, что и игрок: меняют оружие по
  дистанции, отходят ранеными, ищут линию огня.
- **Ранения, а не смерть.** Боец в отряде поднимает упавшего, одиночка — сам
  через 20 секунд. Конец боя наступает, когда поднимать уже некому.
- **Бесконечная прогрессия.** Опыт, уровни, восемь навыков и «изобретения» —
  разгрузка, бронеплиты, FPV-подсумок, радиосеть снабжения, аптечка, фронтовые
  записи. Всё хранится локально и переносится в кооп.
- **Вступительная сцена.** Заход вертолёта над лесополосой, попадание, падение,
  тишина. Пропускается в любой момент.

## Управление

| | |
|---|---|
| `WASD` | движение |
| `Shift` | бег |
| `Ctrl` / `C` | присесть |
| `ПКМ` | прицел |
| `ЛКМ` | огонь |
| `R` | перезарядка |
| `F` | вскрыть ящик снабжения |
| `1–4`, `Q`/`E`, колесо | оружие |
| `Esc` | пауза |

## Кооп

Хост открывает комнату по коду из пяти символов, остальные входят по нему —
до шести бойцов. Хост считает бой на фиксированном шаге 20 Гц и рассылает
снимки состояния, клиенты отправляют только нажатия. Соединение прямое
(WebRTC через сигнальный PeerJS), сервера игры нет.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # headless-тесты симуляции (31 проверка)
npm run typecheck
npm run build      # tsc --noEmit && vite build
```

Код разделён на слои, у каждого одна ответственность:

```
src/core     типы, профиль прогрессии
src/sim      оружие, симуляция боя (детерминированная, без DOM)
src/world    генерация карты, коллизии, лучи, навигационная сетка
src/render   движок, небо, текстуры, мир, сущности, вид оружия, погода
src/game     камера, ввод, звук, постановочная сцена, игровой цикл
src/net      PeerJS-кооп
src/ui       лобби, HUD, экраны (Preact)
test/        headless-проверки симуляции
```

Симуляция ничего не знает о браузере: `test/*.test.ts` гоняют её в Node.
